# Sitepager

Automated website testing that shows you exactly what changed on your site.

Sitepager ([sitepager.io](https://sitepager.io)) scans websites for visual regressions, broken links, SEO issues, and performance problems. It's designed for marketing teams, designers, and agencies who need to catch issues before updates go live.

No code. No plugins. Works with Webflow, Framer, WordPress, and custom sites.

## Use Sitepager with AI

Sitepager ships with an MCP server so AI assistants can run scans, analyze results, apply fixes, and verify after changes are made.

Works with Claude Code, Claude Desktop, Cursor, and Windsurf.

- **MCP server:** [@sitepager/mcp-server](https://www.npmjs.com/package/@sitepager/mcp-server)
- **Docs:** [sitepager.io/docs/guides/connect-sitepager-mcp](https://sitepager.io/docs/guides/connect-sitepager-mcp)
